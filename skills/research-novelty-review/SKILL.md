# 论文idea创新性评估



通过文献对照，识别研究想法的新增贡献、关键问题和验证路径。



## 处理方式

判断创新性时：

1. 优先关注研究动机、核心思想、方法可行性和潜在研究贡献。

2. 发现问题时，先判断它是否会实质性影响研究的正确性、可行性或主要结论。

3. 优先分析会改变创新性、正确性或可行性判断的假设与边界条件，说明其影响路径；其余问题简要记录，按需要展开。

4. 首次完整评估时，先明确研究问题、核心机制和拟主张的贡献，再检索并对照最接近的工作。基于文献对照，说明本想法具体新增了什么、推进了什么，以及这种差异为何有意义；贡献表述的确定程度应与现有证据一致。对支撑创新性或重合判断的关键论文，优先核对正文中的问题设定、核心方法、假设和实验，并提供链接及相关章节、公式或实验位置。区分文献明确结论、分析推断和待验证假设。

5. 对可能导致方法失效、推导错误或实验结论不成立的关键问题，必须明确指出并深入分析。

不追求“绝对原创”或“从未有人做过”，也不要因为已有相似工作就过度防御性地否定一个方向。已有方法在相关问题上的尝试，

并不意味着这个思路失去了价值；以与已有工作相比的实质性新增贡献作为创新性判断的核心。新视角或新的问题组织方式，需要说明其带来的具体认识、方法或可验证结果。分别评估创新性、研究价值和技术可行性，并说明各项判断的依据与待验证之处。

当发现研究思路或技术方案存在问题时：

1. 区分根本性缺陷和可以修正的局部问题，避免将局部不足直接扩大为整个研究框架的问题。

2. 对可以解决的问题，提出调整假设、优化方法或补充实验等具体建议。

3. 优先推荐对现有方案改动较小、实现成本合理，同时能够有效解决问题的方法。

4. 分析修改方案能否保留原有研究思路的核心价值。要求分别判断模块贡献、模块间关系和整体任务贡献，并为拟主张的差异指定一个直接比较实验。

5. 对已经讨论并解决的问题，除非出现新的证据或实质性矛盾，否则不要反复质疑。

6. 每轮讨论尽量形成明确结论，说明当前最值得解决的关键问题，以及下一步可以开展的工作。



## 输出


1. 当前判断：新增贡献是否清晰，现有证据支持到什么程度。
2. 最接近的工作：论文链接、核心方法及与本想法的关系。
3. 关键对照：问题设定、核心机制、假设、已有结果、拟新增贡献及证据。
4. 关键问题：哪些会实质性影响结论，如何修正。
5. 下一步验证：最值得先做的推导、实验或补充检索。
6. 贡献表述：在证据支持时，给出一段准确的贡献论证；证据不足时，明确待验证之处。
